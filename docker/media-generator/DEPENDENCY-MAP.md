# Dependency map: media-generator image

Generated by `docker/media-generator/make-dependency-map.py` from the files in this folder. Do not edit by hand: change the source file, then run `python3 make-dependency-map.py`. `--check` exits 1 when this file is out of date. The image copies this file to `/opt/DEPENDENCY-MAP.md`.

Fixed by the Dockerfile itself: the base image, every `ARG` pin, the npm lockfile and `fonts.txt`. Versions the build resolves at run time (Debian apt packages, chromium) are marked as such.
