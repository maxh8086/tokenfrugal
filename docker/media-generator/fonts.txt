# Open-source font packages baked into the media-generator image (Debian bookworm apt, main component).
# One package per line. The Dockerfile strips comments, then installs the names; the build fails if any name is missing.
# Scope: Latin, Greek and Cyrillic families plus the Noto core/UI/mono/emoji set, serif and display, mono, icon and maths fonts.
# Excluded on purpose: CJK, Indic, Southeast Asian and other regional-script packages (fonts-noto-cjk, fonts-wqy-*, fonts-lohit-*, fonts-tlwg-*, ...)
# and fonts-noto-extra/unhinted/hinted (duplicates). The full main set (498 packages) is about 4.4 GB installed.
# Licences are mostly SIL OFL 1.1 or Apache 2.0; check the package copyright file before a brand uses a family commercially.
