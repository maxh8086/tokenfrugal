# AGENTS.md

Guidance for AI coding agents (Codex, Claude Code, Cursor, others) working on TokenFrugal.

- Purpose: an MCP router (`router/`) that lets a cloud agent delegate routine work to local LLMs. See README.md.
- Run offline tests: `PYTHONPATH=. python -m unittest discover -s tests -t . -q`
- Start the router: `python -m router.server` (stdio MCP). Config comes from `.env` (see `.env.example`).
- Roles, models and tool allowlists: `router/agents.yaml`. Backends: `docker-compose.yml` (project `tokenfrugal`).
- Secrets are Docker secret files in `~/.docker/mcp/secrets`, outside the repo. Never print or commit them.
- Never add co-author trailers or "generated by" footers; the human author is the sole committer.
- Do not install Docker or other software without asking the user first (`python scripts/doctor.py`).

## Teams

- Roles are grouped into teams in `teams:` in `router/tf-roles.yaml`. Membership is fixed per role.
- Each team's lead defaults to `claude-haiku-5-5`, and the orchestrator is `claude-sonnet-5-5`. The orchestrator reviews each lead's result.
- `list_roles` (the tokenfrugal MCP tool) prints every team with its lead, description and roles, plus the orchestrator.
- The lead and orchestrator are cloud models run by the client. The router records them and does not call them.
