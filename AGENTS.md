# AGENTS.md

Guidance for AI coding agents (Codex, Claude Code, Cursor, others) working on TokenFrugal.

- Purpose: an MCP gateway (`gateway/`) that lets a cloud agent delegate routine work to local LLMs. See README.md.
- Run offline tests: `PYTHONPATH=. python -m unittest discover -s tests -t . -q`
- Start the gateway: `python -m gateway.server` (stdio MCP). Config comes from `.env` (see `.env.example`).
- Roles, models and tool allowlists: `gateway/personas.yaml`. Backends: `docker-compose.yml` (project `ts-mcp`).
- Secrets live in `~/.docker/mcp/mcp.env`, outside the repo. Never print or commit them.
- Never add co-author trailers or "generated by" footers; the human author is the sole committer.
- Do not install Docker or other software without asking the user first (`python scripts/doctor.py`).
