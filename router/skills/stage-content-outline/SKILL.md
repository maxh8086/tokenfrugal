# Stage content-outline (stage 1)

Task: slug=<slug>. Work in content/<slug>/.

1. Read the topic and audience named in the task.
2. web_search, then crawl_markdown the 2-3 best pages.
3. Write 01-research.md: Outline (5-7 bullets), Key concepts, Claims table (claim | type | needs source), Source checklist (URLs read).
4. Every statistic, date, company, product, regulation, technical statement and AI model release is a claim. Add no figure from memory.

Output: the file path, then the claim count.
