Configuration

Saved to router/config_overrides.json. The router reads it at start, so restart it to apply (MCP servers can be restarted below without that). Blank fields use the value from .env.

Global settings

MCP servers

Restart recreates a server's backend containers and reconnects to it. The router keeps running. A server used by a running task is skipped.

Roles: model and MCPs

Each role runs one model with the MCPs ticked below. If no MCP is ticked, the role uses its default toolkit.

Expand an agent to change its model and MCP servers. Expand an MCP server to see its tools and set each one to Auto, Ask or Disable. The checkbox sets which MCP servers the agent may use. The Auto / Ask / Disable settings are saved, but the router does not enforce them yet.
